La Aroma Café 

La Aroma Café is a web-based coffee management system designed to provide users with an easy and interactive experience for browsing and managing coffee products.

About The Project
This project is a responsive coffee website that allows users to explore different coffee types, view available products, filter coffees by category, and manage coffee items through an organized interface.

The system includes pages for:
- Viewing all coffees
- Adding new coffee products
- Viewing coffee details
- Filtering coffee products by type

 Features
- Responsive and user-friendly design
- Coffee product management system
- Add, edit, view, and delete coffee items
- Filter coffees by category
- Attractive coffee-themed interface

 Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL Database

 Team Project
This project was developed as a team effort.  
Each team member contributed to designing, developing, and improving different parts of the system.
